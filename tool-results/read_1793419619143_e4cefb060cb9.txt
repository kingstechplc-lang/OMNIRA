     7→     7→// Conventions (inherited from Pharmora)
     8→     8→//  - UUID primary keys (client-generated via Prisma uuid())
     9→     9→//  - Every tenant-owned entity carries organizationId (tenant isolation)
    10→    10→//  - Composite unique constraints scoped per tenant (never global)
    11→    11→//  - Money as Decimal (14,2-equivalent), tax rates as Decimal — never
    12→    12→//    floating point in the database
    13→    13→//  - SQLite: enum-like fields are String constants validated by Zod in
    14→    14→//    the API layer (see src/lib/constants.ts)
    15→    15→//
    16→    16→// Universal business support (new in OMNIRA)
    17→    17→//  - Organization.businessType — a retail vertical pack (supermarket,
    18→    18→//    pharmacy, restaurant, fashion, electronics, hardware, beauty,
    19→    19→//    liquor, bookstore, wholesale, service, general)
    20→    20→//  - Product.trackBatches — perishable/expiry tracking is optional per
    21→    21→//    product (on by default for pharmacy/grocery packs, off elsewhere)
    22→    22→//  - Loyalty accrual on customers; tax per product; multi-warehouse
